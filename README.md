## 📦 Featured Projects
 
### 🗺️ Bosala.ps — Palestinian Business Directory
A geo-aware business discovery platform serving Palestinian businesses.
 
- **Frontend:** React · Vite · TypeScript · Tailwind · PWA
- **Backend:** Node.js · Express · REST APIs · Google OAuth
- **Database:** PostgreSQL 16 · PostGIS · Drizzle ORM
- **Infra:** Ubuntu VPS · Nginx · PM2 (cluster mode) · Cloudflare · Docker
- **Mobile:** PWA + native Android (tested Capacitor, WebView, TWA)
> Migrated geo-queries from Turf.js to PostGIS for ~2.3× faster lookups. Hardened the server with ed25519 SSH keys and fail2ban.
 
### 🎨 Korvex Tool — AI Brand Identity Generator
Windows desktop app that generates complete brand identity packages.
 
- **Stack:** Electron · React · TypeScript · SQLite · Drizzle ORM
- **AI:** Claude API · Recraft V4
- **Packaging:** Professional NSIS installer (.exe, ~400MB, auto-detects VC++ & WebView2)
- **Built from idea to shipped v1 in 5 days**
> Resolved a homography math mismatch in the mockup painting tools and shipped 14+ versions of production hardening (privacy, security, performance).
