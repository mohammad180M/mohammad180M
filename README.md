### 🧰 Kitzos — [kitzos.com](https://kitzos.com)

**Keep your data yours.** A free online-tools platform where every tool runs entirely client-side — no uploads, no signup, no backend. Files never leave the user's device.

- **32 tools across 7 categories** — PDF, images, text, dev tools, calculators, converters & utilities
- Registry-driven architecture: one entry in a single source of truth generates the page, SEO metadata, JSON-LD schema, sitemap & internal linking automatically
- Fully bilingual **English + Arabic (RTL)** with pre-paint locale switching — no flash
- Static export on a global CDN — every tool page ranks independently on search engines

`Next.js 14` `TypeScript` `Tailwind CSS` `pdf-lib` `Canvas API` `Cloudflare Pages`

<br/>

### 🧠 Context Architect — [c8xt.com](https://c8xt.com)

A bilingual, 100% client-side developer platform: command reference, personal notebook, and a visual workflow canvas — all in one static app.

- **1,531 commands across 55 categories**, browsable and copyable
- **225 pre-built workflow templates** covering the full developer lifecycle, each held to a strict automated quality contract
- Visual workflow canvas built on **React Flow** — single write path, undo history, two-tab ownership locking
- All user state lives in the browser (**IndexedDB**) — zero backend, full privacy
- Raw **WebGL2** particle hero rendering the brand mark from 20,000 particles — no 3D libraries
- Automated safety net: **12 end-to-end verifiers** + fleet-wide template audits gate every release

`Next.js 14` `TypeScript` `React Flow` `Dexie / IndexedDB` `WebGL2` `Cloudflare Pages`

<br/>

### 🧭 Bosala Palestine — *the platform that started it all*

A geo-aware Palestinian business directory with its own **fully independent map stack** — built from scratch to respect Palestinian geographic reality. Retired in favor of the company's new platform direction, but the engineering stands:

- **Independent map infrastructure** — self-hosted vector tiles (TileServer-GL), smart routing (Valhalla), and a custom tile-build pipeline from OpenStreetMap + Overture data (2.3M buildings), with Arabic-first labeling
- **AI assistant speaking Palestinian Arabic** — RAG + hybrid search over pgvector embeddings with streaming responses in ~2s
- **Android app published on Google Play**, compatible with 19,000+ devices
- Production-hardened VPS: Docker services, PM2 cluster, CI/CD with health-checked auto-rollback, daily backups & uptime monitoring
- Performance engineering: TTFB ~78ms, mobile bundle cut **-42%**, payload **-79%**, CLS 0.394 → 0

`React 18` `Node.js` `Express` `PostgreSQL 16` `PostGIS` `pgvector` `Drizzle ORM` `Capacitor` `Docker` `Nginx`
