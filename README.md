## 📦 What I've Built

### [Bosala.ps](https://bosala.ps) — Palestinian Business Directory

A geo-aware business discovery platform serving Palestinian businesses, live in production.

- **Stack:** React · Vite · Node.js · Express · PostgreSQL 16 · PostGIS · Drizzle ORM
- **Infra:** Ubuntu VPS · Nginx · PM2 cluster · Cloudflare
- Migrated geo-queries from Turf.js to **PostGIS** → ~**2.3× faster** lookups
- Hardened the server with **ed25519** SSH keys + **fail2ban**

### Korvex Tool — AI Brand Identity Generator

Windows desktop app that generates complete brand identity packages.

- **Stack:** Electron · React · TypeScript · SQLite · Drizzle ORM · Claude API · Recraft V4
- Idea → shipped **v1 in 5 days**
- Professional **NSIS** installer with auto-detection of VC++ & WebView2 dependencies
- Solved a **homography math mismatch** in the mockup painting tools
